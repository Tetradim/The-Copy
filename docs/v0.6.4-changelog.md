# TetherBridge 0.6.4 test build

- USB sessions now use a dedicated loopback framed transport over ADB. It preserves TCP half-close without closing the underlying ADB forward. The Windows app requires the matching Android 0.6.4 app; older Android builds do not expose the framed endpoint.
- The original loopback HTTP proxy remains on port 10888 for older diagnostic scripts; the framed endpoint is on 10889 and must not be exposed to a network.
- HTTPS and a response-after-half-close passed through the Windows relay, ADB, and Samsung Android 16 tablet using an isolated local test server.
- Wireless TLS from 0.6.3 remains available. Physical Wi-Fi/PAN testing, full-device routing, UDP, and Bluetooth socket transport remain unfinished.
