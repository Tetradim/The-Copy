# v0.6.1 changelog

v0.6.1 layers the proxy-mode usability plan on top of the v0.6 hardening base.

## Added

- Windows tabbed companion UI: Status, Traffic, Pairing, Diagnostics, Logs.
- Live traffic/status view combining local relay counters and Android `/status` JSON.
- Android QR/manual pairing payload: `tetherbridge://pair?...`.
- Windows paste-based pairing parser for the Android QR/manual payload.
- Wi-Fi/hotspot assist diagnostics using common phone gateway detection.
- Bluetooth/PAN guidance and a disabled clean-room RFCOMM scaffold for v0.7+.
- Redacted log/diagnostics/support-bundle export.
- v0.7 Wintun/tun2socks full-tunnel investigation notes.

## Fixed in this overlay

- Android `/status` response now uses escaped CRLF and JSON string literals.
- Regression scripts now test the v0.6.1 file names and markers that actually ship.
- Recent logs are retained in a bounded buffer and exported redacted.

## Still intentionally deferred

- Real Wi-Fi Direct/P2P group formation.
- Real Bluetooth RFCOMM data tunnel.
- Full Laptop Routing with Wintun, route/DNS state management, and tun2socks.
- Webcam QR scanning on Windows.
