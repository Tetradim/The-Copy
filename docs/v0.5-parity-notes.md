# v0.5 parity notes

The current clean-room product is closest to the original two-app workflow in USB Bridge mode.

## Covered well

- Android foreground bridge service.
- Windows companion with matching USB/Wi-Fi/PAN cards.
- ADB-forward USB path.
- Current-user proxy enable/restore flow.
- Session-loss restore.
- Token-based Wi-Fi/PAN bridge.
- Basic traffic counters.

## Still missing

- Wi-Fi Direct hotspot creation and discovery.
- Bluetooth RFCOMM data tunnel for cases where native PAN is unavailable.
- Traffic viewer UI with per-connection rows.
- Full-machine routing with a virtual adapter, DNS policy, and route restore.

## Next implementation order

1. Add Wi-Fi Direct discovery/GO assist on Android and a Windows pairing path.
2. Add Bluetooth RFCOMM transport with the same proxy protocol wrapped over a stream.
3. Expand the traffic viewer from aggregate counters to active sessions.
4. Add optional full tunnel as an elevated, separately restorable mode.
