# v0.6.1 Usability Overlay

This release layers the v0.6 feature implementation plan onto the clean-room v0.6 base.

## Implemented in source

- Windows live traffic/status tab.
- Local relay traffic snapshot API.
- Periodic Android `/status` polling and JSON parsing.
- Android QR pairing display using a clean-room `tetherbridge://pair` payload.
- Windows pairing tab that accepts pasted QR payload/manual text.
- Wi-Fi and Bluetooth/PAN guidance in both apps.
- Redacted log buffer and diagnostics export.
- Version bump to Android `0.6.1` / `versionCode=61`.

## Deliberately not faked

- No Wi-Fi Direct group formation button until real P2P code exists.
- No custom Bluetooth RFCOMM tunnel button until real socket transport exists.
- No full laptop routing, Wintun, route changes, DNS changes, or kill switch in v0.6.1.

## Compatibility intent

The goal is to make proxy-bridge mode feel more complete for daily use while preserving the clean-room boundary: no original app package names, strings, icons, code, certificates, or private protocol behavior are copied.

## Added as v0.7 design research

- Wintun/tun2socks investigation notes for future Full Laptop Routing.
- No full-tunnel code is active in v0.6.1.
