# v0.6.2 changelog

v0.6.2 is a TCP SOCKS5 foundation and survivability pass. It does not enable Wintun, tun2socks, route changes, DNS changes, or full laptop routing.

## Added

- Windows local TCP-only SOCKS5 relay on `127.0.0.1:10810`.
- SOCKS5 `CONNECT` translation to the existing phone HTTP `CONNECT` bridge.
- SOCKS5 relay counters in the Windows Traffic tab and support bundle.
- Explicit `UDP_ASSOCIATE_UNSUPPORTED` logging for SOCKS5 UDP requests.
- Full-tunnel docs now point v0.7 tun2socks experiments at `socks5://127.0.0.1:10810`.

## Fixed

- Restored Windows HTTP relay admission control with `SemaphoreSlim`.
- Restored the Windows HTTP relay initial-header timeout.
- Added `Proxy-Authorization` redaction to support bundle export.
- Bumped source version markers to `0.6.2`.

## Still deferred

- Full-device routing.
- Wintun adapter creation.
- tun2socks process lifecycle.
- DNS and route snapshot/restore.
- UDP ASSOCIATE or custom UDP relay.
