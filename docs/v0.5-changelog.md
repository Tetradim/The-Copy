# v0.5 changelog

v0.5 is a correctness and feature-visibility pass on top of v0.4.

## Fixed

- Android `readHeader` now returns both the header block and any bytes that were read past the `\r\n\r\n` terminator.
- Windows `LocalRelayProxy.ReadHeaderAsync` now preserves over-read bytes instead of silently dropping them.
- Android plain-HTTP forwarding now strips `X-TetherBridge-Token` before forwarding to the origin server.
- Windows phone transport now returns a `NetworkStream` that owns the underlying socket, preventing relay socket leaks.
- Windows mode switching no longer overwrites the user's true proxy baseline with TetherBridge's own temporary local proxy.

## Added

- Android `ConnectionStats` with active connection, total connection, upload byte, and download byte counters.
- Android `/status` endpoint.
- Windows "View Traffic Status" button.
- Windows WinHTTP proxy inspector for diagnostics.
- USB reconnect/re-forward attempt before session-loss proxy restore.
- Static regression checks for the v0.5 issues above.

## Still not done

- Real Wi-Fi Direct bridge.
- Real Bluetooth RFCOMM bridge.
- Full laptop routing.
- Persistent HTTP proxy connection reuse.
- Installer signing and binary build verification.
