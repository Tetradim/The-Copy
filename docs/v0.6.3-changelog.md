# TetherBridge 0.6.3 test build

- Wi-Fi/PAN proxy transport requires TLS 1.2 or newer and a SHA-256 certificate fingerprint in the Android pairing payload. Old wireless clients and pairing payloads are incompatible; update both applications and pair again through a trusted channel.
- The Android certificate private key is held in Android Keystore. The Windows client pins its certificate before sending the pairing token.
- Windows HTTP and SOCKS relays isolate listener lifetimes and preserve orderly TCP half-closes.
- USB remains an ADB-forwarded loopback proxy; full-device routing, UDP, Wi-Fi Direct, and a Bluetooth socket tunnel are not implemented.
- The encrypted transport has been tested through ADB on one Samsung Android 16 tablet. A real Wi-Fi/PAN path and the OnePlus remain unverified.
