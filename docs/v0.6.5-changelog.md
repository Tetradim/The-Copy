# TetherBridge Windows 0.6.5 test build

- The Windows status tab lists ADB devices and lets the user select the intended Android device. Automatic selection works when exactly one device is authorized and ready. A missing selected device never causes the app to choose another device automatically.
- USB connection, pairing injection, recovery, diagnostics, and owned-forward cleanup use the selected serial. An existing owned forward is recognized; a missing forward is recreated without rebinding another mapping.
- Checking a missing device happens before stopping an existing TetherBridge session. Diagnostics no longer report an absent Android app as installed.
- Android remains at 0.6.4; the 0.6.5 Windows app uses the same framed USB protocol. No Android update is needed for this Windows-only change.
- Multi-device cases were tested with simulated ADB output; the connected Samsung tablet was selected and its test forward created and removed on the real device. The OnePlus was not connected for a live multi-device test.
