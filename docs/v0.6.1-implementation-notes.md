# v0.6.1 implementation notes

## Scope

v0.6.1 keeps full-tunnel routing deferred and focuses on the visible proxy-mode parity gaps: traffic visibility, easy pairing, better mode guidance, logs, and diagnostics export.

## QR pairing

Android emits a clean-room payload:

```text
tetherbridge://pair?version=0.6.1&mode=wifi&host=<phone-ip>&port=10888&token=<token>
```

Windows can parse that payload from a paste box. Webcam QR scanning is intentionally not included yet because it would add camera permissions/libraries to the Windows app and is not required for end-to-end pairing.

## Wi-Fi and Bluetooth honesty

v0.6.1 adds Wi-Fi/hotspot assist diagnostics and a Bluetooth RFCOMM scaffold, but it does not expose fake Wi-Fi Direct or fake Bluetooth socket buttons. Those remain v0.7+ transport work.

## Support export

The support bundle includes local relay counters, phone `/status`, diagnostics, and recent logs. The active token is redacted before writing the file.


## Verification notes

The package includes static regression marker checks for the corrected Android header/body path, per-peer auth backoff, honest UI boundaries, QR pairing payloads, Windows status polling, redacted export, Wi-Fi/Bluetooth guidance, and the v0.7 full-tunnel investigation notes. Real Android and Windows binary builds still require Android Studio/Gradle and a Windows .NET SDK environment.
